# kirill-news-reportsAI

Автоматические AI-отчёты о трендах замены людей агентами.

Генерируются агентом Hermes каждый вторник и пятницу.

## Структура

- `/reports/YYYY-MM/` — отчёты по месяцам
- Каждый файл: `YYYY-MM-DD-report.md`

## Темы мониторинга

- Массовые увольнения из-за AI-агентов
- Замена ролей автоматизацией
- Кейсы внедрения агентов в корпорациях
- Тренды рынка труда под давлением AI
